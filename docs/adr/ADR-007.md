# ADR-007: Usar Expo Image Picker y Expo File System para capturar y conservar las fotos

## Estado
Aceptado.

## Fecha
27 de octubre del 2026

## Requisitos relacionados
R6, cuando el consumo es anómalo y se debe adjuntar una fotografía del medidor. R7, al capturar la foto y conservarla en el teléfono hasta que la lectura sea enviada.

## Contexto
La aplicación permite que el técnico registre lecturas de medidores de agua y adjunte fotografías como evidencia. La foto es obligatoria cuando el consumo es anómalo o el medidor está dañado, y opcional en los demás casos.

## Alternativas consideradas

| Alternativa | Ventajas en este proyecto | Desventajas en este proyecto |
| :--- | :--- | :--- |
| **Expo Image Picker y Expo File System** | Permiten capturar fotografías y conservar los archivos localmente para utilizarlos posteriormente durante el envío de las lecturas. Se integran con el entorno Expo. | Requieren configurar los permisos necesarios y administrar las rutas de los archivos para evitar perder las fotografías antes de enviarlas. |
| **Expo Camera** | Permite acceder a la cámara y capturar fotografías desde la aplicación. Ofrece control sobre la experiencia de captura. | Requiere implementar una interfaz de cámara y administrar el proceso de captura, lo que puede agregar complejidad si solo se necesita tomar una foto del medidor. |

## Decisión
Se usan Expo Image Picker y Expo File System para capturar las fotografías de los medidores y conservarlas en el almacenamiento local del teléfono. Esta combinación permite asociar cada imagen con su lectura y mantenerla disponible hasta que el registro se envíe al sistema de la oficina.

## Consecuencias
- Se agregan las dependencias necesarias para capturar y administrar los archivos de las fotografías.
- Se deben configurar los permisos de cámara y explicar al técnico por qué se necesitan.
- Si el técnico no concede el permiso de cámara, la aplicación debe permitir continuar sin fotografía cuando esta sea opcional y exigirla cuando corresponda.

## Verificación
- Capturar una fotografía del medidor y comprobar que se guarda correctamente en el teléfono.
- Cerrar y volver a abrir la aplicación y comprobar que la fotografía continúa disponible.
- Registrar una lectura con fotografía y comprobar que su ruta queda asociada al registro almacenado en Expo SQLite.
- Mantener una lectura pendiente durante varios días y comprobar que la fotografía sigue disponible.
- Denegar el permiso de cámara y comprobar que la aplicación explica su necesidad y permite continuar cuando la fotografía es opcional.

## Uso de IA
Se le pidió a la IA comparar Expo Image Picker y Expo Camera y conservar fotografías en una aplicación móvil de registro de lecturas. La IA recomendó Expo Image Picker junto con Expo File System,
